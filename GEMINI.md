# PURSUE Data Analyzer - Project Guidelines\n\n## Core Directives\n*   **NO NATIVE OCR:** Never use OS-native OCR APIs (e.g., Apple Vision Framework, Windows Media OCR). They produce unacceptable artifacting, character substitution errors (e.g., numbers instead of letters), and broken formatting. We require high-fidelity, deterministic OCR (like neural vision models) regardless of the payload size.
